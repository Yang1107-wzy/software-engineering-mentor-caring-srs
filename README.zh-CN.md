# Mentor Caring System 软件需求规格说明

[English](README.md) · 软件工程课程项目 · B04 小组

## 项目概览

该小组项目为拟议的 Mentor Caring System 编写需求与设计视图。规格说明涵盖用户和权限、用例、外部接口、非功能需求及相关图表。它是**需求工程成果**，不能据此声称已经建成或部署生产级网页系统。

## 我的贡献与依据

SRS 封面将王正旸列为六位编写成员之一。仓库包含 LaTeX 源码（`main.tex` 和 `sections/`）、图表（`images/` 及图表目录）和[编译后的 SRS](reports/mentor-caring-srs.pdf)。现有文件没有把具体章节或图逐一分配到个人，因此作者贡献按小组层级表述。

## 阅读与构建

建议先读编译版 PDF。若要从源码构建，安装含 `pdflatex` 的 LaTeX 环境，在仓库根目录运行 `pdflatex -interaction=nonstopmode main.tex`，再运行第二遍以更新交叉引用和目录。PDF 是本仓库源码的阅读版本。

## 局限

需求和图表描述的是预期行为，并非系统实现、用户测试、校内正式部署或项目验收证明。仓库原有课程文件保留。
