# Mentor Caring System: Software Requirements Specification

[简体中文](README.zh-CN.md) · Software Engineering course project · Group B04

## Project at a glance

This group project documents the requirements and design views for a proposed Mentor Caring System. The specification covers users and permissions, use cases, external interfaces, non-functional requirements, and supporting diagrams. It is a **requirements-engineering deliverable**, not evidence that a production web application was built or deployed.

## My contribution and evidence

The SRS title page names Zhengyang Wang among the six preparers. The repository contains the LaTeX source (`main.tex` and `sections/`), figures (`images/` and diagram directories), and the [compiled SRS](reports/mentor-caring-srs.pdf). The available files do not assign particular sections or diagrams to individual members, so authorship is stated at group level.

## How to review or build

Read the compiled SRS first. To build from source, install a LaTeX distribution with `pdflatex`, then run `pdflatex -interaction=nonstopmode main.tex` from the repository root; a second pass updates references and the table of contents. The compiled PDF is a reading copy of this repository's source.

## Limits

Requirements and diagrams describe intended behavior. They are not implementation, user testing, institutional deployment, or evidence of acceptance by the programme. The original course files remain in place.
